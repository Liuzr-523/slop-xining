# 地面连接与街具碰撞 · 0.6.1

## 已确认的原因

1. 隧道车道的限宽从地面端点就开始生效，挡墙也从端点连续生成。玩家即使尚未下沉，也会被拉回车道。NPC按地面路线运动，没有使用该玩家隧道限宽，因此出现同一处NPC能穿过、玩家被挡住的现象。
2. 生成街具时的避让半径被直接复用为碰撞范围。江汉路花坛预留半径2m，但实际花坛边长2.8m；旧式路灯预留半径0.55m，实际杆脚半径约0.12m；长椅不应使用大正方形，停放踏板车也应按朝向处理。预留的空隙曾成为看不见的障碍。
3. 双幅桥面的外侧护栏连续延伸至贴地端点，没有按当地地面高程放开连接。

## 修复

- 增加共用的侧向保护判定：相对街面下沉/抬升超过0.75m才闭合侧边。这是显示与驾驶规则，不是实测工程参数。
- 隧道浅端仍跟随路面高度，但不限制横向离开；侧边渲染与接触共用判定。深处继续限宽，避免把洞内也放开导致车辆穿墙或掉出。
- 双幅桥面护栏及其碰撞按相对当地山地高度裁切；地面连接不设护栏。保留桥面连续支撑和高处护栏。
- 碰撞与生成避让分离：杆件用贴近杆脚的多边形，花坛基座和树干分别处理，长椅采用旋转矩形，踏板车按模型实际包围范围与朝向处理。树木与路灯碰撞高度随生成位置移动，未知的预留记录不自动生成碰撞；关闭树木的调试选项不会留下树干碰撞。
- NPC仍按原来的道路网络运行，本次没有将全部NPC改为玩家同等级的车辆物理。地面区域不再依赖NPC穿墙来表现连通。

## 验证

- 四个隧道口各向左右正常驾驶，8种情况全部驶出超过6m，没有被限宽拉回；保留普通道路和物件碰撞。
- 两个方向完整跨江，均从源地面道路进入并驶回另一岸地面道路，无卡住、掉出或错误弹回地面。
- 单元覆盖地面侧向退出、地面与地下侧边判定一致、高地桥面相对高度、街具可见尺寸与实际出租车擦边通过。
- 76项JavaScript测试、22项Python测试通过，空间审计与生产构建通过。自动物理测试记录保存在[验收目录](acceptance/0.6.1/)。

这些修复针对已确认的碰撞过大和入口限宽问题，不能据此宣称所有街区的潜在碰撞问题均已排除。
