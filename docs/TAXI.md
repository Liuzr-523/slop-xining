# 出租车接送 · 0.10.0

汽车模式点击“开始接单”（或按T），查看随机订单后接受。沿黄色导航去接乘客，上车后沿青色路线送达，停车下客并结算。不默认强制营业，可以随时取消并继续自由漫游。

## 订单范围与随机机制

取消0.9.0的三条固定汉口短途路线，也取消汉口服务区和2.5公里接客限制。起终点从地图内自动生成的可停靠路边位置随机选取，可出现在汉口、武昌或汉阳。接客位置偏向附近，但不设接客或载客行程的最大距离；较长的行程和跨江订单都可能出现。接单前同时显示接客里程、目的地、载客里程、预计时间与虚拟车费。

每次订单都检查当前车辆到乘客、乘客到终点的有向道路连通性。单行方向保留，路线沿真实道路折线计算，不把直线跨江当作可达。跨江可走已有大桥和武汉长江隧道；隧道两条单向主洞使用原有OSM入口/出口节点身份连接地面路网，不合并空间上接近但不同身份、不同高程的路口。

没有最大行程长度。只剔除同一点或几乎原地上下车：起终点平面间距大于35米、道路行程至少80米，且避免立即重复同一对起终点。站点由道路长度、宽度、方向和场景条件自动计算，不逐条编写订单。

## 停靠和路线是否合法

- 上下客点设在普通机动车道路边，避开桥面、隧道、快速路、匝道、步行街、水面、建筑和地图边界。
- 校验停靠方向、车辆占地、实际地形高度、坡度、路口距离以及乘客走向车辆的通道，避开树、灯柱、停放两轮车等静态碰撞物。
- 桥梁、隧道和快速路可以参与行程，但不在上面随机生成上下客点。
- 路网过滤没有实际桥面承托的水上道路、与地面明显错层的道路，以及场景中找不到连续车宽通道的路段。部分自动生成建筑可能挤进源道路，因此不能只根据地图上画了线就派单。
- 找不到可达且有效的订单时会提示换路，并可主动前往附近候客路段；不会自动传送或强制返回汉口。派单尝试次数有计算量上限，但不是距离上限。

## 接送、计费与取消

距停靠点7米以内、车速低于约4km/h、处在相同高度层，停车约1.8秒；随后用2秒简化步行动作上下车。提前开走会退回等待停靠。

虚拟计费为起步8元，加实际行驶公里数与时间，不代表现实武汉运价。结算记录本单距离、用时、收入、起终点与当班完成单数；同一单不会重复支付。收入只保存在当前页面会话，无账号、真实支付或排行榜。

地图打开或页面进入后台时不推进计时、停车保持与上下车。切换载具、传送、取消本单不会获得收入。偏航时从当前道路重新寻路，不改变玩家位置。合法导航不能消除正常车流或代替玩家转向、避让。

## 实现与参考

参考London Loop的任务分层、道路导航和上下车思路，适配武汉运行系统。

- `taxi-routing.js`：单行有向寻路、分层道路投影、路边停靠位置、可达性查询。
- `taxi-network.js`：全图道路筛选、已有隧道拓扑接入、路边候车点生成。
- `taxi-dispatch.js`：按可达性和停靠条件随机配对，无固定线路表。
- `taxi-trip.js`：接单、停车、上下车、计程计时、结算和取消状态机。
- `taxi-fare.js`：场景碰撞走廊校验、可见乘客、简体中文界面，以及路面、小地图和全屏地图共用的导航。

## 验证

规则测试覆盖单行、孤立路网、超过13公里的可达订单、停靠方向、隧道节点身份、防止近距离错误拼接、建筑阻断路段、停靠计时、取消和不重复支付。固定随机种子的160单数据测试覆盖三镇、大桥、隧道、短单及超过10公里的行程。

完整Chrome场景另从汉口、武昌、汉阳各通过正常界面生成20单，共60单。路网过滤后本轮最长订单约20.9公里，包含经大桥和长江隧道的行程；单次生成最高约11ms，未发现浏览器运行错误。全场景候选停靠点约3,175个，最终派单还会检查车身和乘客通道。

一单使用正常油门、转向与刹车完成接客、上车、送达、下车及结算：从汉口集贤二路到武昌文明路，经长江隧道，车上实际行驶约16,594米、1,500.73秒，虚拟收入49.9元，只支付一次；途中不传送或强制推进任务状态。导航数据覆盖更多路线，不等于逐条整程实驾验证全部随机组合。

复现：启动本机服务后运行：

```sh
node tools/taxi-session.mjs --verify --trips 1 --seed 20261102 --max-seconds 3000 --url http://127.0.0.1:4803/
```

Playwright在其他目录安装时用`--playwright /path/to/playwright/index.mjs`；`--trips`控制单数，`--seed`控制验证随机数，`--max-seconds`仅限制测试脚本的最长模拟时间。生产派单不固定随机种子，也不受这个模拟时限限制。报告与截图位于`output/taxi-random/`、`output/taxi-random-drive/`，不纳入Git。

0.9.0三条固定路线的约31秒演示视频仍保留在原素材目录，属于旧版玩法记录，不作为0.10.0全图随机接送的整程实驾证明。
