# 路边不可见树木 · 0.6.2

用户报告很多道路开向路边都会撞到看不见的东西。本次没有继续凭碰撞尺寸猜测，直接对照实际场景与碰撞生成记录。

## 根因

`createTreeField`创建了树木组、几何、实例及近中远细节选择，调用方也为树木位置生成了碰撞。但创建函数与调用方均未将返回的树木组挂入场景。修复前普通密度模式生成38,890棵树，场景中却找不到`Trees`组。树木无需网络加载，因此不会产生下载失败或脚本错误，之前只核对数量和错误日志没有识别出缺失。

0.6.1修改的街具碰撞尺寸确有问题，但没有覆盖这一更普遍的缺失显示问题。

## 修复及验证

树木创建函数现在负责把组加入传入场景。已有生成位置、细节切换和碰撞保留，显示真实存在的树干与树冠。

新增`tests/browser/runtime-tree-visibility.js`，在真实浏览器中沿江大道、中山大道、京汉大道各选取行道树集中的位置，检查车辆40m内每个树木位置都有可见实例，并验证组仍属于显示场景。该检查通过实际运行场景验证挂接、实例数量与位置；单看生成数量或编写源码文本匹配测试无法覆盖这类错误。

开发版本三条道路分别核对34、44、41棵树，共119棵，缺失0；实际截图可见行道树和树影。浏览器无运行错误，测试机器所取最近180帧平均约16.66ms。该性能样本仅代表这次验收位置和机器。

76项JavaScript测试、22项Python测试、空间审计及生产构建通过。生产版本另外重复同一浏览器检查，记录见[验收目录](acceptance/0.6.2/)；浏览器检查函数可交由现有Playwright CLI的run-code运行，需要已加载武汉运行页面。
