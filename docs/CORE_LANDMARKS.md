## 黄鹤楼模型依据

实际查看了[武汉市政府2025年实景照片](https://japanese.wuhan.gov.cn/wh_rywz01/wh_rywz012/202508/t20250801_2628422.shtml)中的主体正面及屋面近景。原模型只是普通方楼叠单一屋顶，与实景中中央屋顶、角部屋面交错的轮廓差异明显。

[湖北省文旅厅](https://wlt.hubei.gov.cn/bmdt/ztzl/lszt/hszjbjc/xwbd_hs/202109/t20210927_3783772.shtml)说明其为“四边套八边”、外观五层；[湖北省住建厅](https://zjt.hubei.gov.cn/bmdt/ztzl/hbcjda/gzdt_7471/201910/t20191028_79891.shtml)列出51.4m总高、折角正方形平面、72根圆柱及60个翘角。

新版采用中央楼身与角部翼块、五组中央及角部曲面屋顶、外廊和栏杆、72根示意立柱、青绿檐下装饰、深色门窗和葫芦宝顶；总高控制为51.4m。琉璃瓦、砖材是本地程序生成纹理，未把受版权保护的照片贴到模型上。柱位、屋面小尺寸、彩画、窗格和书法仍为近似，未宣称完成测绘级复原或精确逐一重建60个翘角。

红楼身份依据[武昌区政府介绍](https://www.wuchang.gov.cn/zjwc/wcly/you/zmjd/202005/t20200507_1241528.html)及原始建筑轮廓；18m外观总高属于估计。它对应北区军政府旧址，不与另一个南区辛亥革命博物馆混用。

## 高度筛查与已处理项

`tools/audit-building-heights.py` 遍历每栋生成建筑，筛选有名称仍为低楼占位的商务建筑、仅有模型低估值的候选、大占地整体等高挤出的高层，以及仅按楼层换算的高层。输出 JSON 和带中文列名的 CSV。**候选不是确认错误**；低层商场本来就可能低矮，不能只凭“大厦”“广场”等名称加高。

本轮逐项修订资料见 `data/source/building-evidence.json`：

- 绿地中心：原OSM取整476m，统一为专业建筑数据库的475.6m；不是把它当作层高错误大幅修改。
- 武汉长江中心：原12m占位；采用[CVU当前记录](https://www.skyscrapercenter.com/building/great-river-center/39970)的400m建筑总高，并保留“结构封顶、尚非已确认竣工高度”的状态。2021年[官方施工报道](https://www.wuhan.gov.cn/zwgk/xxgk/zdjsxm/ssqk/202102/t20210218_1635905.shtml)的386.3m作为历史口径保留。它在武昌，不与汉口长江航运中心混淆。
- 武汉万达中心：原12m占位；依据[项目开发方新闻稿](https://www.prnasia.com/story/44290-1.shtml)的约180m办公楼说明修订。其他资料有188m口径，暂未完成竣工高度核对，明确标为“公开近似值”。这栋与“万达尊B座”不是同一建筑。
- 恒隆商场：依据[Aedas项目申报](https://architectureprize.com/winners/winner.php?id=4658)的六层商场，按估计商业层高5m显示为30m；办公塔楼仍采用单独轮廓与320.7m总高。

“中国银行大厦”等名称不足以证明它就是212.4m的湖北分行总部；未直接套用同名高楼的数据。“万达尊B座”现有楼层与其他同名项目可能混淆，保留待核对。边界附近的阿里中心也应先检查被裁剪的轮廓，再决定如何应用完整塔楼高度。

原PBF中武汉中心 `way/450740194` 的轮廓范围约为114.23937—114.23997°E、30.59638—30.59689°N，超出本项目114.252—114.336°E、30.54—30.5942°N外框。王家墩CBD的缺席首先是范围问题。本轮没有扩区，也不把它搬进现有区域。
