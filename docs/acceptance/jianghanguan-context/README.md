# 江汉关初始视角修正 · 2026-10-29

## 已修正

- 江汉关 OSM 主体为凹形轮廓，邻楼 `osm-building-way-128400513-0` 与其接壤。旧模型主体正确，但各层檐口、屋顶、侧面窗格仍依外接矩形生成，进入凹口和邻楼。现在横向楼层和屋顶均使用真实轮廓三角化，门窗沿真实边界排列；前立面柱列使用真实正立面宽度。移除越界的两个简化四角坡屋顶，保留钟楼。
- 补充数据 `overture-125f76ab-8aa9-461d-9085-4e95e08dd4ad` 的占地约 28 平方米，高约 26.825 米。它处在凹口中，地面多边形去重无法识别，但与专用钟楼上层体积相交。以具体来源 ID 记录为专用模型组件并排除第二次渲染，保留周边建筑；身份移动超出 12 米则中止构建，避免静默误删。
- 日信洋行保留来源中的五层，增加中央浅半圆阳台、上层连续阳台。后续按历史商业楼层高调整显示包络至约 22 米，原 OSM 楼层推算的 16 米保留在高度变更证据中，不称为实测。参考武汉出版社《日信洋行》的建筑描述，细节尺寸为估算，突出控制在约 0.38 米，不扩大碰撞占地。

- 按用户明确要求，江汉关朝向继续使用现有 `l.ry`；未旋转主体、柱廊、入口或钟面朝向。

- 第三处日清—日信街区：源轮廓保留；日信五层原来按每层 3.2 米压成 16 米，现在采用约 22 米的历史商业楼显示包络（20–24 米估算范围）。这不是新增实测高度，也没有凭空填造建筑占地。
