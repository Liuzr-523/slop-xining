# 0.8.1 汉口沿江—江汉路历史建筑群

本轮把历史建筑从普通建筑材质中分离，首批绑定12栋现有OSM建筑。范围与1:1坐标不变，没有把整个沿江街区统一改成某一种“欧式”样式。

## 资料与外观依据

[武汉市档案馆](https://www.whda.org.cn/dawh/whjy/202512/t20251223_2699331.shtml)对江汉路建筑的说明区分了早期古典柱廊与后期简洁的近代建筑，因此四明、永利和中国实业银行不套用古典圆柱模板。

## 自动化生成方式

1. `config/hankou-heritage.json`按OSM ID和预期名称双重绑定，名称不符时停止应用，避免同名或邻楼误匹配。
2. 数据阶段保留原始轮廓及高度来源，附加立面类型、主立面朝向和资料链接。没有按“距离江边近”或“名称里带银行”来批量匹配。
3. 运行时从真实多边形的边界生成窗间节奏、拱窗、砌缝、角石、檐口和栏杆。汇丰、花旗、台湾银行和日清的中段墙体向轮廓内退进，形成有实际深度的柱廊。
4. 装饰浅浮雕约在原轮廓外0.3m内；主体和碰撞继续使用同一OSM轮廓。不在道路外加台阶或栏杆碰撞。
5. 按共享材质合并每栋几何，并接入现有场景剔除系统；不会把每个窗框变成独立绘制对象。照片不作为外部运行依赖。
6. 地图加入12栋旧址名称与搜索入口，传送到附近经过检查的道路；原有全市10处代表地标保留。相机菜单新增“汉口沿江历史建筑群”。

参考台北`js/landmarks.js`中总统府、西门红楼按轮廓组装体量及合并材质的方式，以及`createPreWarBuildingMaterial`对石材、窗间节奏的参数化思路；武汉继续复用既有台北运行系统。上海的导入与轮廓合同保留。没有复制台北地标外形来充当汉口建筑。

## 高度处理与剩余差距

[武汉出版社《汉口五国租界》](https://www.whcbs.com/Upload/BookReadFile/202004/8bcbb02411c04eb6b90f150e861056bb.pdf)在花旗银行条目中记载29.5m，本轮采用该值替代冲突的OSM 20m，保留改前值。

台湾银行23m、汇丰24m、日清32m（含圆顶）、四明31m是用于外观的照片包络估计，分别保留20—26m、21—27m、28—35m、28—35m估计范围。它们不是实测高度，也没有把它们写成OSM高度。其他七栋沿用原高度与原显示估计规则。

本轮没有复原精确雕花、石狮、文字铭文及全部窗位；也没有将现代店招还原成清末民国时期。目标是当前城市中的历史建筑风貌。下一步可以继续逐栋收集正立面及侧面照片，将类型近似升级为专用参数，重点补足横滨正金银行的顶层、日信洋行及上海银行的具体构图。

## 验证

源轮廓不变，主体模型有内凹柱廊；检查几何有限数值、外扩边界、面数、地图到达点及高度来源。完整记录与浏览器截图索引见`docs/acceptance/0.8.1/`，截图位于`output/playwright/heritage-*.png`。
