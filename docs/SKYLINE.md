# 0.7.0 武汉滨江天际线校正

本轮保持原范围、真实距离、道路、水岸、地形和隧道。改动集中在建筑体量与外观，不把所有建筑统一拉高，也不在南岸嘴绿地凭空补楼。

## 核对资料与判断

实际查看了武汉市水务局转载的[2021年南岸嘴航拍照片](https://swj.wuhan.gov.cn/tzdt/jcss/202109/t20210917_1779604.html)，结合本地 OSM 建筑位置、部件和楼层资料，核对两江交汇附近的建筑轮廓。照片用于判断楼群、裙房、塔楼、绿地的关系；不是摄影测量。相关官方航拍视频页也已检索，但视频未成功播放，本轮不声称完成视频逐帧核对。

原先的不足包括：导入遗漏 `building:part`，把裙房当成整栋楼；部分滨江高层只有默认低楼高度；用途和立面模板过于统一。现有 3D-GloBFP 高度主要仍是2020年模型估计，不能视为实测，也不能通过全局倍增解决。

## 自动化修复

`tools/import-citywide.py` 单独保留 OSM 建筑部件。`tools/building_parts.py` 按几何包含关系寻找最小合适母建筑，保留部件轮廓、顶部高度与底部高度。塔楼不再把整个大裙房拉高；已有人工参考体量保留优先级。源部件与母建筑边界的微小误差裁回母建筑内部，继续满足道路与建筑分离检查。

本次源数据98个部件中，60个有效部件匹配到33栋建筑；29个缺少有效高度，9个没有合适母建筑，暂不猜测补入。33是母建筑数量，60是部件数量，不代表新增60栋独立建筑。原来兼有 `building` 和 `building:part` 的两个重复独立记录也已归并。

所有修订在 `data/source/building-evidence.json` 记录身份、资料链接和高度含义。运行数据保留塔楼部件来源及参考链接；照片估计的两栋 `sourceHeight` 留空，避免把显示高度当成真实数据。

## 表现变化

- 60m以上、用途已判为住宅的建筑采用浅色现代住宅立面；指定滨江住宅、办公楼和酒店分别应用对应模板。
- 晴川饭店使用白色墙面和深色横向窗带，是体量识别用的程序化示意，不是精细历史建筑复原。
- 减少通用彩钢屋顶加盖，取消缺乏资料支持的随机圆形屋顶水箱。保留原有汉口历史街区表现。
- 本轮不新增随机建筑填充“密度”；通过恢复既有建筑的垂直体量改善层次。世茂锦绣长江等其他楼群尚未逐栋完成高度校准。

在相机菜单新增“汉口滨江天际线”“南岸嘴与晴川饭店”“积玉桥滨江楼群”三个固定视角，便于直接复核。

## 验证与复现

执行 `npm run data:build` 可从当前固定来源重建；`npm run verify` 检查源部件规则、真实数据集的裙房/塔楼分离、五栋住宅和两栋照片估计的高度来源，以及现有道路、水面和地形约束。

浏览器以正午、50°视场、固定相同相机位置对比0.6.3与0.7.0的汉口江岸、晴川饭店和积玉桥三组画面；结果保存在 `output/playwright/skyline-before-*.png` 和 `skyline-after-*.png`。截图中的固定相机只用于检查，不改变玩家位置或控制代码。

仍有大量普通建筑依赖估计高度，照片也早于当前数据年份。本轮完成的是一批有依据的校正，尚不能称为完整、精确的武汉天际线复原。
