# 江汉路—江汉关街景迭代

延续上海运行系统，范围仍为汉口试验区。本轮以江汉路走到沿江大道、辨认江汉关为验收路线。

| 任务 | 具体实现 | 验收 |
| --- | --- | --- |
| 数据补齐 | 查询 Overture 小范围建筑，与 OSM 按几何去重；保留来源、快照和高度可信度 | 新增量可量化，无重复堆楼；缺高度仍明确标估算 |
| 建筑恢复 | 渲染真实外环/内院；使用原轮廓进行路面冲突判断；同步碰撞 | 不规则建筑和院落可见；不再因为矩形包围盒删掉整栋楼 |
| 道路核查 | 保留原 OSM 节点、宽度/车道标签；补导入 path/steps/cycleway；分别呈现步行铺装和车道 | 生成连通审计；江汉路步行段可连续走到沿江大道；不把立交交叉误接平面 |
| 江汉关 | 以 OSM 江汉关大楼轮廓定位，参考公开实景制作钟楼、石材主楼和柱廊 | 地图可检索/到达；轮廓和朝向对齐；独立近景与沿街远景可辨认 |
| 重点街段 | 江汉路末段与沿江大道沿线的铺装、树列、灯具、座椅与临街细节 | 风格保持现有世界；装饰不堵路、不侵占建筑和水域 |
| 浏览器验收 | 固定江汉关近景、街段远景、全区俯瞰；步行/驾驶/地点跳转 | 无启动错误；性能与前版比较；报告保留数据缺口 |

江汉关模型为基于 OSM 平面和实景参考的简化外观，不是测绘模型。高度暂采用武汉市政府转载报道中的约 45.85m；其他来源常见 46.3m，两者口径不同，记录差异，不使用“钟楼 83.8m”这类混淆海拔与建筑高度的说法。

资料：https://3g.wuhan.gov.cn/sy/kwh/202401/t20240122_2347703.shtml

## 本轮完成情况 · 0.2.0

- 数据：固定 Overture 2026-10-21.0 提取 2,253 项，几何去重及过滤后新增 1,675 栋；保留 422 栋 OSM 普通建筑，江汉关单独建模。
- 建筑：所有普通建筑改为原始外环与内院体量，新增轮廓碰撞；未再按矩形占路删除建筑。
- 道路：新增导入 path/steps/cycleway，优先 width 或车道数，独立步行铺装。现为 404 段道路；保留源节点 ID，江汉路与沿江大道位于同一连通分量，未添加猜测连接线。
- 地标：江汉关可在地图检索、选择和到达，默认朝向建筑；钟楼、四面钟盘、8 根廊柱及主楼石材细节均已生成。
- 街段：江汉路末段加入石带、树列、灯具、座椅，博物馆邻近沿江路侧加入矮柱。街具为表现性估算。
- 验证：45 项测试与生产构建通过；浏览器检验步行/驾驶/飞行到达均成功。江汉路中心线 152 个采样点碰撞推离为 0；这项检查不能替代对整条道路宽度与所有岔口的人工验收。

下一轮仍需：可靠楼高（本轮 2,083 栋仍按 12m 估算）、具体街道立面和商铺资料、桥隧高差。江汉关是可辨识的简化外观模型，未制作室内、完整雕饰或文物级精度。
